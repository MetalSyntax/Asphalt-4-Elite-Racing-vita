## 1b. Engine, lifecycle and middleware analysis (2026-11-04, evidence = `decompiled/macho/*`, `tools/annotate.py`)

- **Engine:** Gameloft in-house J2ME/BREW-heritage code, no third-party engine (`grep -ciE "cocos2d|unity|sio2|oolong|box2d" symbols.txt` = 0).
  Symbols: `Lib3D::*` (141+26), `CHighGear::*` (83, the Asphalt game class), `CLib2D`, `CGapi`, `CKeypad`, `CTouchZones`,
  `CArchivedFileManager` (.bar archives) with a statically linked zlib (`_inflate*` at 0x57c58..). Fixed-point Lib3D with some VFP
  (`.long 0xed9..` VFP loads); **no VFP vector mode**: 0 `fmxr fpscr` words in `__text` (scan of `(w & 0x0fff0fff) == 0x0ee10a10`),
  so the Blades/HoS2 FPSCR.LEN fix is not needed. Not PIE (`otool -hv`: no PIE flag) -> `__text` literal pools and 672 ARM switch
  jump-table entries are rebased (HoS2 `tools/macho_prep.py`, 4720 words).
- **App delegate / view:** `UIApplicationMain(argc, argv, nil, @"GLoftApp")` (`_main` 0x5e48c). No nib (Info.plist has no
  `NSMainNibFile`). `-[GLoftApp applicationDidFinishLaunching:]` (0x5d498): `UIWindow initWithFrame:[UIScreen bounds]`,
  `UIGLView alloc initWithFrame:` (ivar `m_GLView`, returned by `-[GLoftApp view]` 0x5d44c), `setMultipleTouchEnabled:`,
  `addSubview:`, `makeKeyAndVisible`, `UIDevice model/systemVersion`, `LoadMovie("asphalt4.mp4")`, `pthread_create(ThreadRoutine)`.
- **Frame loop:** a game thread, not a timer. `ThreadRoutine` (0x5d1d4): `ChangeCurrentDirToApplicationDir`, `InitOpenGLESWindow`
  (EAGLContext ES1 + FBO/RBO + `renderbufferStorage:fromDrawable:`), `GameInit` (sets `m_bIsRunning`), then forever
  `UIViewBeginRender / GameLoop / UIViewEndRender`; `UIViewEndRender` (0x5dbd4) = `presentRenderbuffer:` +
  `CFRunLoopRunInMode(default, 0.001)` + `sched_yield`. Main thread only runs UIKit (touches, NSTimers, notifications).
- **Orientation:** `Gapi+0x164` (`_Gapi` 0x200ee8) = 2 or 4 (landscape); `_UpdateTouchPress` (0x5cbb8) rotates touches with it.
  `GetPhoneOrientation` (0x60d28) returns -1 (no change) for a flat accelerometer.
- **Resources:** `ChangeCurrentDirToApplicationDir` (0x5d038): `CFBundleCopyBundleURL` -> `CFURLCopyFileSystemPath` ->
  `CFStringGetCString`, cut at the last `/`, + hardcoded `"/ASPHALT4.app/"` = `g_AppPath`; `CWinFile::Create` (0x5b6cc)
  opens `sprintf("%s%s", g_AppPath, name)` (resources) or `GetSaveFilePath` (= `NSSearchPathForDirectoriesInDomains(9)` Documents)
  -> **the staged bundle folder must be named `ASPHALT4.app`** (`BUNDLE_PATH` in `source/hle.h`). `pathForResource:ofType:` only
  for the movie (`-[MoviePlayer initWithFile:]`).
- **Audio (Apple SoundEngine/CrashLanding + Gameloft wrappers):** SFX: `SoundManager::loadAllEffect` -> `CSoundWrap::SampleLoad`
  -> `SoundEngine_LoadEffect(data, size)` -> `SoundEngineEffect::AttachFilesToSource` parses each in-memory WAV with
  **AudioFileStream** (`SoundDataParser` listeners 0x627ac/0x6281c: `bcnt` read with 4 bytes, `dfmt` 40 bytes) and
  `alBufferData`. 16 WAVs in `sounds.bar`, all PCM s16 mono 44.1 kHz. Music: `CSoundWrap::MusicLoad` (0x5cf6c) ->

- **Video:** one file, `asphalt4.mp4` = MPEG-4 Part 2 Simple Profile 480x320 25 fps + AAC-LC 44.1 kHz, 40.7 s. Flow:
  `CHighGear::GameLoop` -> `PlayMovie` -> `-[MoviePlayer playMovie]` (0x65258: schedules `execPlay` NSTimer, waits for

- **Input:** touches -> `-[UIGLView touchesChangedWithEvent:]` -> `UpdateTouchPress/Move/Release` -> the singleton

## 2. What gets decompiled in an IPA (and what does not)

An IPA is a zip: `Payload/<App>.app/` = **one** Mach-O executable + resources. All game code is in
that executable (unless `Frameworks/*.dylib` exist -- 32-bit-era games almost never have them).

| Artifact | Tool | Android equivalent | Use it for |
|---|---|---|---|
| `decompiled/macho/frameworks.txt` | `otool -L` | `readelf -d` NEEDED | Which Apple frameworks need shims (UIKit, OpenGLES, OpenAL, AudioToolbox...). |
| `decompiled/macho/objc_classes.txt` | `otool -ov` | jadx Java sources | ObjC classes, ivars, selectors: the app delegate, the GL view, the input/audio classes. |
| `decompiled/macho/symbols.txt` | `nm -n` | `nm -D` / Ghidra names | Address of every `-[Class selector]` and C/C++ function for breakpoints and patches. |
| `decompiled/macho/imports.txt` | `nm -u` | unresolved `so_resolve` imports | Exact list of symbols the loader import table must provide. |
| `decompiled/ASPHALT4_<arch>/ghidra/` | Ghidra (devrvk/so-decompiler) | `decompiled/<lib>_<abi>/ghidra/` | Pseudo-C of the game logic, for crash triage and hooks. |
| `tools/annotate.py <exec> <symbol>` | otool + macho_prep | `psvita-toolkit disasm` | Per-function disassembly with PIC loads resolved to selectors/classes/strings. |

Do NOT decompile: resources (`.png` CgBI, `.plist`, audio, `.nib`) -- they are loaded as-is
(`source/cgbi.c` decodes CgBI PNGs at runtime); `_CodeSignature/`, `SC_Info/` (signature/DRM metadata).

## 4. iOS-on-Vita ABI rules (violating any of these = random crashes)

1. **`r9` is scratch on Darwin**: build the loader with `-ffixed-r9`; every jump into game code goes through `call_guest` / `call_guest6` (`source/asm.S`).
2. **SoftFP**: floats travel in `r0..r3`. Vendored vitaGL MUST be built with `SOFTFP_ABI=1`. Any shim taking `float`/`double` uses `__attribute__((pcs("aapcs")))`.
3. **4-byte stack**: iOS only aligns `sp` to 4. Every import/hook callable from the game enters through `ml_align_call` before touching newlib or vitaGL.
4. **Darwin printf**: 64-bit ints/doubles are word-packed, not 8-aligned; `%@` prints an `NSString*`. Route all game printf/NSLog through `darwin_printf.c` (`tools/printf_check.py` validates).
5. **ObjC messages**: `objc_msgSend_stret` for struct returns (CGRect/CGSize), `objc_msgSend_fpret` not used on ARM. Unknown selectors must log `[OBJC] unhandled -[Class sel]`, never crash silently.

## 6. Crash triage loop

1. Stage and deploy data: `tools/stage_data.sh` then `psvita-toolkit deploy --data` (or `python3 -I tools/deploy_data.py`).
2. Pull logs: `python3 -I tools/deploy_data.py --logs` → newest `logs/asphalt4eliteracing_NNN.log`.
3. Dump: `psvita-toolkit analyze <dump>.psp2dmp --elf build/asphalt4eliteracing`.
4. PC in `0x98xxxxxx` → game code: subtract `0x98000000`, find the function in `decompiled/macho/symbols.txt`, then `python3 -I tools/annotate.py game_app/ASPHALT4 '<symbol>'` and the Ghidra pseudo-C.
5. PC in the loader → it's our shim: check the ABI rules (section 4) first.

## 7. On-console log standard

The game log lives at `ux0:data/asphalt4eliteracing/logs/asphalt4eliteracing_NNN.log` -- concretely `asphalt4eliteracing_001.log`,
`asphalt4eliteracing_002.log`, ... up to `asphalt4eliteracing_999.log`, then wraps to 001. Never `log_NNN.log`, never
`log_<timestamp>.txt`, never 000-based, never a hardcoded path: build it from `LOGS_PATH`
(`source/hle.h`). Use the levels `l_info` / `l_warn` / `l_error` / `l_fatal` and tag subsystems
(`[MACHO]`, `[OBJC]`, `[GL]`, `[AUDIO]`, `[INPUT]`, `[UNIMPL]`) so logs can be grepped.
Toolkit: `psvita-toolkit log-standard --fix-dirs`, `psvita-toolkit log-trace --ensure-flag`.
